# 💬 IPChat in .NET

A TCP-based chat application built in **C# / .NET 9** with a desktop GUI and separated chat logic layer.

## Technologies

- C# / .NET 9
- TCP Sockets
- WinForms

## Features

- Real-time messaging over TCP/IP
- Desktop GUI for sending and receiving messages
- Chat logic separated from the UI layer

## Getting Started

### Requirements

- .NET 9 SDK => https://dotnet.microsoft.com/download
- Visual Studio 2022 or newer

## Project Structure

```
ChatGUI/         → Desktop GUI (WinForms/WPF)
ChatLogic/       → TCP connection and message handling logic
ConsoleApp1/     → Console-based entry point / testing
ConsoleApp1.sln  → Visual Studio solution file
```
